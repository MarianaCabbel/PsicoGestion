# Riesgos

| Riesgo                                                                                                                                              | Impacto                                                                                | Mitigación / seguimiento                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| SQLite es el valor predeterminado para desarrollo y pruebas; las diferencias con el motor de producción pueden revelar problemas de compatibilidad. | Alto al desplegar cambios de esquema o transacciones.                                  | Ejecutar periódicamente `npm run test:pg` con una base PostgreSQL de pruebas y verificar las migraciones allí.                                     |
| JWT, CORS y SMTP dependen de variables de entorno sensibles.                                                                                        | Exposición de cuentas o indisponibilidad de autenticación/correo si se configuran mal. | Mantener secretos fuera del repositorio y validar la configuración del entorno antes de producción.                                                |
| Las notificaciones dependen de un servicio SMTP externo.                                                                                            | Retrasos o fallos en confirmaciones por correo.                                        | Supervisar errores y definir el proceso operativo de reintento y atención.                                                                         |
| No hay todavía objetivos operativos documentados para disponibilidad, rendimiento ni recuperación.                                                  | Dificultad para medir la preparación y responder a incidentes.                         | Acordar objetivos y procedimientos para el entorno de despliegue.                                                                                  |
| La cobertura frontend está en 31.03%, por debajo del objetivo de 70%.                                                                               | Regresiones en páginas de negocio podrían no detectarse automáticamente.               | Priorizar pruebas de agenda, citas, salas, terapeutas y autenticación; no cerrar la Fase 6 hasta cumplir el umbral.                                |
| La complejidad ciclomática de seis funciones supera el valor de referencia 10; la máxima es 21.                                                     | Mayor dificultad para mantener y verificar rutas de disponibilidad y autorización.     | Planificar refactorizaciones pequeñas respaldadas por pruebas, empezando por disponibilidad de citas.                                              |
| La instalación actual informó 60 vulnerabilidades en el árbol de dependencias (6 críticas, 42 altas, 10 moderadas y 2 bajas).                       | Riesgo de seguridad en dependencias directas o transitivas.                            | Revisar el detalle con `npm audit` y planificar actualizaciones en un cambio dedicado; no se actualizaron dependencias de aplicación en esta fase. |
